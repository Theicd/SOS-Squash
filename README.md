# SOS Squash

כיווץ וידאו אוטומטי בדפדפן — הקובץ לא עוזב את המכשיר.

**לינק חי:** https://theicd.github.io/SOS-Squash/

## שימוש

1. פתח את הלינק ב־Chrome / Edge
2. גרור וידאו → לחץ **כווץ**
3. הורד את התוצאה

הממשק בוחר לבד רזולוציה וקצב, שומר על השמע, ומדלג על קבצים שכבר דחוסים היטב.

## הרצה מקומית (Windows)

לחיצה כפולה על `start-squash-lab.bat`, או:

```bash
npm start
```

נפתח ב־http://127.0.0.1:8787/
